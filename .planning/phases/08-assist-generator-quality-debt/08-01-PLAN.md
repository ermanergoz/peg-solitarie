<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| persisted resume blob → `BoardSpec` | A tampered or corrupt snapshot can propose an arbitrary `minimumPegs`. The blob is app-written but not trusted (existing T-05-03/T-05-04 discipline). |
| `:domain` main ← generated Challenge footprints | The generator constructs `BoardSpec`s at runtime; a target above 1 there would silently break Challenge hints. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Tampering | `BoardSpec.minimumPegs` | mitigate | `init { require(minimumPegs in 1..size) }` in `BoardSpec` (Task 1) as defence in depth; the fail-closed decode boundary is `SnapshotMapper`, validated in plan 08-07. Without this, a forged `minimumPegs <= 0` makes the solver's `pegCount <= minimumPegs` goal test trivially true and every hint permanently `null`. |
| T-08-02 | Tampering | `BoardSpec.footprint` used as an opening-book lookup key | accept | The key is derived from in-play positions the app itself constructed and is already validated for well-formedness by `SnapshotMapper.toBoardSpecOrNull`. A forged footprint yields a book miss (solver fallback), not a wrong move — and every book hit is re-validated against `RulesEngine.legalMoves` downstream (plan 08-10). |
| T-08-03 | Denial of Service | Freeform Challenge footprints | mitigate | Task 3 asserts generated footprints keep `minimumPegs = 1`, so the Pagoda prune stays at full strength on generated boards (Pitfall 1's weakened-prune CPU cost is confined to Diamond-41). |
| T-08-SC | Tampering | package-manager installs | n/a | This phase installs no packages — RESEARCH §Package Legitimacy Audit records zero new coordinates. `domain/build.gradle.kts` declares only the already-pinned `libs.junit` + `libs.truth`. |
</threat_model>
