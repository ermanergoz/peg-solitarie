<objective>
## Phase Goal (MVP user story)

**As a** peg-solitaire player, **I want to** ask for a hint that reveals a genuine next winning move and undo my last move, **so that** I can get unstuck and keep playing a puzzle that stays fair and always winnable.

## This plan's slice

Finish the assist experience with the **rescue state**: an inline, non-blocking banner shown over the still-interactive board when the position is genuinely unsolvable (Solver returned null / budget miss, D-04) or when the board is stuck (D-06). The banner reads "No winning move — undo or restart" (or the parallel stuck copy) and offers Undo · Restart · Home (D-09). Critically, a stuck board no longer auto-routes to Results (revising Phase-3 D-10) — it becomes rescuable via Undo — while a Won game still proceeds to Results as before. This is the assist that makes the guaranteed-solvable ladder feel fair.

Purpose: ASST-03 (clear "no winning move" state) + D-06/D-08/D-09.
Output: shared `NoWinBanner`, the VM stuck-rescue state-machine change (narrow the `finished` emission to Won; unify stuck + no-win into one rescue flag; timer resume on rescue-undo), banner wiring, strings/dimens, and VM + Compose tests. This is the trickiest state interaction in the phase — the VM change carries the heaviest test coverage.
</objective>
