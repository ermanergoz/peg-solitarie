<objective>
## Phase Goal (MVP user story)

**As a** peg-solitaire player, **I want to** ask for a hint that reveals a genuine next winning move and undo my last move, **so that** I can get unstuck and keep playing a puzzle that stays fair and always winnable.

## This plan's slice

A single human-verification checkpoint: play the assembled assist features on a device/emulator and confirm the hint highlight legibility (glow + A->B arrow), the thinking indicator, the no-win/stuck rescue banner, and multi-step Undo rescue all feel right. Automated tests already lock behavior (plans 04-01..04-04); this checkpoint covers the one thing tests cannot — subjective visual/interaction quality (VALIDATION.md "Manual-Only Verifications"), mirroring the Phase-3 on-device playability checkpoint.

Purpose: final sign-off on ASST-01/02/03 as a felt, playable experience before phase verification.
Output: user approval (or a punch list of visual/interaction fixes to fold back via gap closure).
</objective>

  <what-built>
    The complete Phase-4 assist feature set, playable end-to-end:
    - Hint control (magnifying-glass) that reveals the next winning move: source-peg glow + target-hole ring + faint A->B arrow, in the tertiary accent (distinct from the primary selection color). It never auto-plays the move — you tap to perform it.
    - A brief "thinking" spinner on the Hint control while the Solver runs (Classic hints and post-deviation Challenge hints); usually sub-second.
    - The renamed "Show possible moves" toggle (legal-destination dots) — now unmistakably distinct from "Hint".
    - Undo control that steps back one move per tap, all the way to the start, with the timer left running.
    - The non-blocking rescue banner ("No winning move — undo or restart" / "No moves left — undo or restart") over the still-interactive board, offering Undo · Restart · Home, shown on a genuinely-unsolvable or stuck position instead of auto-navigating to Results.
  </what-built>
  <how-to-verify>
    Install the debug APK (`./gradlew :app:installDebug` or install the assembled APK) and verify:
    1. CHALLENGE HINT (recorded line): Start Challenge level 1. Tap Hint. Confirm a peg glows (source), a hole is ringed (target), and a faint arrow points source→target — legibly, and clearly different from tapping a peg to select it. Perform the highlighted move yourself; confirm the hint did NOT auto-play it.
    2. THINKING + FALLBACK: In a Classic board (e.g. English-33), make a few moves, then tap Hint. Confirm a brief spinner appears on the Hint control, then a valid winning move is highlighted. In Challenge, deviate from the hinted move, then tap Hint again and confirm it still returns a sensible winning move (Solver fallback) — never a wrong or illegal highlight.
    3. NO-WIN / STUCK BANNER: Play a board into a dead end (or a no-winning-move position). Confirm the game does NOT jump to the Results screen; instead the inline banner appears over the still-tappable board with Undo · Restart · Home, and the copy reads as specified.
    4. UNDO RESCUE: From that stuck/no-win state, tap Undo and confirm the board backs up into a playable position and the banner clears; keep tapping Undo back toward the start; confirm the elapsed timer kept counting the whole time (Undo costs time, not a penalty).
    5. WON UNCHANGED: Solve a board to one peg; confirm it still proceeds to the Results screen as before (the rescue is only for stuck/no-win).
  </how-to-verify>
