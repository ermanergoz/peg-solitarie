integration property. Proving it here is what makes every later plan's conflict handling honest.

`ProgressMergeLimits.kt` — a scoped constants `object` with a KDoc per member naming *why that
value*: `NO_STARS = 0`, `NO_SCORE = 0`, `NO_TIME_RECORDED = Long.MAX_VALUE`, `DEFAULT_LADDER = 1`,

equals `ChallengeProgressPreferences.DEFAULT_CURRENT_LEVEL` and `ChallengeLevelBounds.MIN`; note in
KDoc that `:domain` cannot reference the `app`-module preference constant, so the equality is
asserted by the codec test in plan 13-03 rather than by a shared symbol.

`CloudProgress.kt` — the four pure declarations in the `<interfaces>` block above. `ProgressMode` is
a domain enum, NOT the on-disk `ProgressPersistenceKeys.MODE_CLASSIC`/`MODE_CHALLENGE` strings and
NOT the wire tokens (Pitfall 11); its KDoc must say so and name plan 13-03's `data/cloud/` mapper as
the only place the translation lives. Note the deliberate deviation from the RESEARCH sketch:
`LevelBest` carries **only** the three merged fields, because `mode` and `levelId` already live in
the `LevelKey` that indexes it, and duplicating them would create a second place for them to
disagree. `completedAt` is deliberately absent — its KDoc must carry the RESEARCH reason: it means
"last improved on THIS device", has no cross-device meaning, and syncing it would make the merge
non-idempotent.

`ProgressMerge.kt` — `object ProgressMerge` with the three functions. `merge(LevelBest, LevelBest)`
is `maxOf(stars)` / `minOf(bestTimeMs)` / `maxOf(bestScore)`. `merge(CloudProgress, CloudProgress)`
is `maxOf(ladder)`, `maxOf(playedTimeMs)`, and a union over `a.bests.keys + b.bests.keys` where a
key present on one side only is taken verbatim. `dropLowestChallenge(progress, count)` partitions
`bests` by `key.mode`, sorts the CHALLENGE partition by `key.levelId.toIntOrNull() ?: Int.MAX_VALUE`
ascending (an unparseable Challenge id sorts LAST so a malformed row is dropped only after every
well-formed one), drops the first `count.coerceAtLeast(0)`, and rebuilds `CloudProgress` with the
untouched `ladder`, `playedTimeMs` and every CLASSIC entry.
