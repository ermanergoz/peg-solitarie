<objective>
Reshape the `GamesService` seam so a submission failure is an **observable event**, give the real
`PlayGamesService` working bodies for all five (now six) Phase-12 methods, and add the two
signed-in-only Settings entry points into the stock Play Games UIs.

Purpose: every later plan in this phase depends on this shape. Plan 12-07's `ProgressSubmitter`
cannot implement D-10's dirty flag against `void`-returning methods (there is no failure to
observe), and PGSL-06 / PGSA-05 have no entry point until the two Settings rows exist. D-16
(stock unlock popup untouched) is discharged here by construction: v2 exposes no popup API at
all, so the correct implementation is zero lines, and this plan records that fact rather than
leaving a future reader to rediscover it.

Output: a `Boolean`-returning, `Activity`-free seam; a `PlayGamesService` that talks to
`LeaderboardsClient` / `AchievementsClient` through the `*Immediate` + `Task.await()` forms and
launches the two SDK-provided Intents with `startActivityForResult`; a recording
`FakeGamesService` the rest of the phase tests against; and two new Settings rows.

**Not in this plan:** nothing calls the submission methods yet. `GamesIds`, the ID plumbing, the
`ProgressSubmitter` and the `ResultsViewModel` hook are plans 12-04 / 12-07. **No leaderboard or
achievement ID literal may appear in any file this plan touches** — IDs stay opaque `String`
parameters.
</objective>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| `ui/` → `platform/games` (the seam) | The only path from a ViewModel to the Play Games SDK. Nothing but Kotlin primitives crosses it: no `android.app.Activity`, no `com.google.android.gms.*` type. |
| `platform/games` → Play Games Services v2 (Google process, IPC) | Every call may fail with a `RemoteException`, a dropped call while signed out, or an unavailable Play services. Failure is data (`false`), never an exception the player sees. |
| Play Games Services → app (returned `Task<Intent>`) | The stock-UI Intent is SDK-authored and launched unmodified at a Google-owned component. |
| App process → R8/minification (release build) | The new `LeaderboardsClient` / `AchievementsClient` reflection crosses the Dynamite boundary. |
