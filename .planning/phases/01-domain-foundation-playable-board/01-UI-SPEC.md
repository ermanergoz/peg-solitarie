# Phase 1 — UI Design Contract

> Visual and interaction contract for the single **playable English-33 board screen**. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> This is a native Android **Jetpack Compose + Material 3** game (Compose BOM 2026.06.00), not a web/shadcn project. The board is drawn on a Compose `Canvas`; the only Material composables are the top app bar, an `AlertDialog` (game-over, D-05) and a confirm dialog (mid-game restart, D-06). Theming/polish beyond one clean baseline theme is deferred to Slice 2 (POLI-01).
>
> **Hard project constraints baked into this contract (CLAUDE.md / QUAL-03):**
> - Every fixed dp/sp value is a `res/values/dimens.xml` token — no raw dp/sp literals in composables.
> - Every color is a **Material 3 theme role** (`MaterialTheme.colorScheme.*`) — no hex literals in composables.
> - Unitless values (ratios, animation durations in ms, grid dimension) are **scoped constants objects** (e.g. `BoardMetrics`, `GameAnim`) — not dimens.xml (which is dp/sp only), and never inline magic numbers.
> - All composables stateless/state-hoisted; `GameViewModel` owns one immutable `GameUiState` over `StateFlow`.

## Spacing Scale

8-point scale (all multiples of 4), declared as `dimens.xml` tokens. Fixed-dp tokens only — board geometry that scales with canvas size is expressed as **ratios** in the Board Visual Model below, not as dp.

| Token (dimens.xml) | Value | Usage |
|--------------------|-------|-------|
| `spacing_xs` | 4dp | Inline gaps, dialog content row gaps |
| `spacing_sm` | 8dp | Compact spacing (button row gaps) |
| `spacing_md` | 16dp | Default spacing; screen edge / board outer margin |
| `spacing_lg` | 24dp | Dialog inner padding, section breaks |
| `spacing_xl` | 32dp | Vertical breathing room above/below board on tall screens |

**Phase-specific layout tokens (dimens.xml) — multiples of 4:**

| Token | Value | Usage |
|-------|-------|-------|
| `board_screen_margin` | 16dp | Min margin between board and screen edges |
| `board_max_size` | 480dp | Cap on board square edge (prevents oversized board on tablets) |
| `board_min_touch_target` | 48dp | Material 3 minimum touch target — board must size so each cell ≥ this; otherwise board shrinks gracefully but cells never go below tap-comfortable |
| `top_bar_icon_size` | 24dp | Restart icon size (M3 default) |
| `dialog_padding` | 24dp | AlertDialog / confirm dialog content padding |

**Stroke widths (rendering, exempt from the 8-point grid):**

These two tokens are **stroke-width rendering properties, not layout spacing** — they define the thickness of a drawn outline, not the size of or gap between layout elements. They are deliberately sub-4dp and are an **intentional exception** to the multiples-of-4 rule (a 4dp peg ring or hole outline would visually overpower the small peg geometry). Do not "round" them up to satisfy the 8-point grid.

| Token (dimens.xml) | Value | Usage |
|--------------------|-------|-------|
| `peg_selected_ring_width` | 3dp | Stroke width of the selected-peg `primary` ring (rendering, not spacing) |
| `hole_outline_width` | 1dp | Stroke width of the empty-hole `outlineVariant` ring (rendering, not spacing) |

Exceptions: board cell size, peg radius, hole radius, and highlight radii are **computed from canvas size** (`cellSize = min(width, height) / GRID_DIMENSION`) and expressed as unitless ratio constants in `BoardMetrics` — they are intentionally **not** dimens.xml entries because they are proportional, not fixed dp. This is compliant with QUAL-03 (the no-dp/sp-literal gate targets fixed literals in composables; ratios live in a scoped constants object).

## Typography

Material 3 type-scale roles only (no invented sizes). M3 maps these to sp internally through `Typography`, so composables reference `MaterialTheme.typography.*` — no raw sp literals. Exactly **two weights** across the phase: Regular (400) + Medium (500).

| Role | M3 token | Size / Weight / Line-height (M3 default) | Usage |
|------|----------|------------------------------------------|-------|
| Top-bar title | `titleLarge` | 22sp / Medium 500 / 28sp | App bar title "Peg Solitaire" |
| Dialog headline | `headlineSmall` | 24sp / Regular 400 / 32sp | Game-over message + confirm title |
| Body | `bodyMedium` | 14sp / Regular 400 / 20sp (1.43) | Pegs-remaining text, confirm body |
| Button label | `labelLarge` | 14sp / Medium 500 / 20sp | Dialog + confirm button labels |

Weights used: **400 (Regular)**, **500 (Medium)** — two only.

## Color

Material 3 role mapping for the 60/30/10 balance. In a peg board the "10% accent" is reserved for **transient interaction state** (selection + legal destinations + the dialog primary action) — never for the 33 resting pegs, which form the 30% mass.

| Role | M3 token | Usage |
|------|----------|-------|
| Dominant (60%) | `surface` / `background` | Screen behind the board |
| Secondary (30%) — board panel | `surfaceContainerHigh` | Rounded board panel the grid sits on |
| Secondary (30%) — pegs (resting) | `secondary` (filled circle) | The 33 game pieces in their default, unselected state |
| Empty hole | fill `surfaceContainerLowest` + ring `outlineVariant` (1dp) | Recessed-hole look for `Cell.Empty` |
| Accent (10%) — selected peg | peg keeps `secondary` fill + ring `primary` (3dp) + subtle scale-up | The one currently-selected peg |
| Accent (10%) — legal destination | filled dot `primary` @ 38% alpha, radius `DESTINATION_DOT_RATIO × cellSize`, centered in the target empty hole | Where the selected peg may land (D-04 highlight) |
| Accent (10%) — dialog primary | `primary` (filled/text button) | "Play Again" / "Restart Board" primary actions |
| On-content text | `onSurface` / `onSurfaceVariant` | Dialog and app-bar text |
| Jumped-peg removal | the peg's own `secondary` fill animating alpha→0 | D-08 fade |
| Blocked cells | not drawn (transparent) | Cells outside the English-33 footprint |
| Destructive | **none** — see note | — |

**Accent reserved for:** (1) the selected peg's `primary` ring, (2) legal-destination dots, (3) the primary action button in the game-over and confirm dialogs. Nothing else uses `primary`. At any moment the accent is at most 1 selected peg + ≤4 destination dots + 1 button — comfortably under 10% of the surface.

**Destructive color note:** Phase 1 has no data-destructive action. Restart discards in-progress moves, but per casual-game feel it is **not** styled with the `error` role. The mid-game confirm (D-06) is the safeguard; its confirm button uses `primary`, dismiss uses a neutral text button. No `error`/red is used anywhere in Phase 1. Rationale: a benign board reset should not alarm a casual player.

## Board Visual Model

> The board is a 7×7 grid (English-33: the 33-hole cross). Drawn on one Compose `Canvas`. Geometry is hoisted once via `remember(boardSpec, canvasSize)` — **never allocate inside `DrawScope`** (RESEARCH Pitfall 8).

**Primary focal point:** the centered board panel is the sole screen content (no competing chrome beyond the slim top app bar), so it is the unambiguous focal point of the screen; during interaction the **selected peg** (its `primary` ring + 1.08× scale) becomes the in-game focal point, drawing the eye to the active piece and its highlighted legal destinations.

**Scoped constants object `BoardMetrics` (unitless ratios — NOT dimens.xml):**

| Constant | Value | Meaning |
|----------|-------|---------|
| `GRID_DIMENSION` | 7 | English-33 occupies a 7×7 lattice |
| `PEG_RADIUS_RATIO` | 0.34 | peg radius = ratio × cellSize |
| `HOLE_RADIUS_RATIO` | 0.16 | empty-hole indicator radius |
| `DESTINATION_DOT_RATIO` | 0.18 | legal-destination dot radius |
| `SELECTED_RING_RATIO` | 0.40 | selected-peg ring radius (outer) |
| `SELECTED_PEG_SCALE` | 1.08 | selected peg grows slightly for affordance |
| `REMOVAL_SCALE_TARGET` | 0.30 | jumped peg shrinks to this before vanishing (D-08) |
| `DESTINATION_DOT_ALPHA` | 0.38 | alpha of the `primary` destination dot |

**Per-cell rendering:**

| Cell state | Drawn as |
|------------|----------|
| `Blocked` (off the cross) | nothing (transparent) |
| `Empty` | `surfaceContainerLowest` filled circle (`HOLE_RADIUS_RATIO`) + 1dp `outlineVariant` ring → reads as a recessed hole |
| `Empty` **and** a legal destination | the hole + a `primary`@`DESTINATION_DOT_ALPHA` filled dot (`DESTINATION_DOT_RATIO`) |
| `Peg` (resting) | `secondary` filled circle (`PEG_RADIUS_RATIO`) |
| `Peg` (selected) | `secondary` fill scaled `SELECTED_PEG_SCALE` + `primary` ring (`peg_selected_ring_width`, `SELECTED_RING_RATIO`) |
| `Peg` (jumping) | drawn at the animated `Offset` between source and destination centers (D-07) |
| `Peg` (being jumped over) | drawn fading alpha 1→0 and scaling 1→`REMOVAL_SCALE_TARGET` (D-08) |

Board panel: a single `surfaceContainerHigh` rounded-rect (corner = M3 large shape) behind the grid, inset by `board_screen_margin`, square, capped at `board_max_size`, centered.

## Interaction & Animation Contract

> Honors locked decisions D-02..D-08 verbatim. All logic lives in `GameViewModel`; the `Canvas` only emits `onCellTap(Position)` upward and renders `GameUiState` (RESEARCH Q5 / Anti-Pattern 1).

**Tap behavior (D-02 / D-03 / D-04):**

| Tap target | Behavior |
|------------|----------|
| A player's peg, none selected | Select it; compute + highlight its legal destinations |
| The currently-selected peg | Deselect; clear highlights (D-04) |
| A different player's peg | Re-select that peg; recompute highlights (D-04) |
| A highlighted legal destination | Perform the jump — **always two-step, no auto-jump even with one option** (D-03); then evaluate game-over |
| An empty/blocked/illegal cell while a peg is selected | **No-op** — does NOT deselect (D-04) |

**Animation tokens — scoped constants object `GameAnim` (Int milliseconds, NOT dimens.xml):**

| Constant | Value | Easing | Drives |
|----------|-------|--------|--------|
| `JUMP_SLIDE_MS` | 200 | `FastOutSlowInEasing` | Jumper straight-line slide source→destination (D-07) |
| `REMOVAL_MS` | 180 | `FastOutLinearInEasing` | Jumped peg alpha 1→0 + scale 1→`REMOVAL_SCALE_TARGET` (D-08) |
| `SELECT_FADE_MS` | 120 | `LinearEasing` | Selection ring / destination dots fade in |

Both jump and removal animations **launch together** keyed on `moveHistory.size`; removal (180ms) finishes just as the jumper lands (200ms), per D-08. `onAnimationFinished()` fires after the slide completes; the VM has already committed the move to domain state (animate-from-committed-state, RESEARCH Q5). Legal-destination highlights are **static** in Phase 1 (no pulse — pulse is Slice-2 polish).

**Restart (D-06):**
- Persistent control: a top-app-bar action, `Icons.Rounded.Refresh`, size `top_bar_icon_size`, tint `onSurface`, `contentDescription = "Restart Board"`.
- If `moveHistory.isNotEmpty()` and not at end-state → show the mid-game confirm dialog first.
- At end-state → the dialog's "Play Again" restarts with no extra confirm.
- Restart resets `GameState` to the hardcoded English-33 initial board (center empty).

**Game-over (D-05):** modeled as `GameUiState.status ∈ {Won, Stuck}` (replayable state, survives rotation — **not** a one-shot effect). Renders an M3 `AlertDialog` overlay (see copy below).

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA (game-over dialog) | **"Play Again"** |
| Restart control (top bar) | icon-only; `contentDescription` = **"Restart Board"** |
| Game-over — perfect (pegs == 1) | Headline: **"Perfect!"** · Body: **"You cleared the board down to a single peg."** |
| Game-over — near (pegs 2–3) | Headline: **"So close!"** · Body: **"{n} pegs remaining."** (stars arrive in Phase 2) |
| Game-over — stuck (pegs ≥ 4) | Headline: **"No moves left"** · Body: **"{n} pegs remaining. Try again?"** |
| Game-over dialog dismiss | Text button **"View Board"** (hides the overlay so the player can view the final board; Restart still available in the top bar) |
| Mid-game restart confirm | Title: **"Restart this board?"** · Body: **"Your current progress will be lost."** · Confirm: **"Restart Board"** · Dismiss: **"Keep Playing"** |
| Empty state | **N/A** — the board is never data-empty; it always renders the English-33 layout (full board, center hole) as its initial state. |
| Error state | **N/A** — no network/load/auth in Phase 1. Illegal/out-of-board taps fail closed as silent no-ops (D-04); the domain never crashes on bad input. |

**Button-copy rationale:** every action label names its outcome rather than using a bare verb or a generic dismiss word. **"Restart Board"** (not bare "Restart") and **"Play Again"** name the object acted on. The game-over dismiss is **"View Board"** (not "Close") because dismissing the overlay returns the player to look at the final board. The mid-game dismiss is **"Keep Playing"** (not "Cancel") because choosing it keeps the player in their current, in-progress game session — communicating the outcome, not a generic abort.

All literal strings live in `res/values/strings.xml` (no hardcoded UI strings — CLAUDE.md no-magic-strings rule); `{n}` is a plural-aware resource (`plurals` for "peg/pegs").
