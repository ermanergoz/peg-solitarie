`AdGateway` (MODIFIED, package `com.app.pegsolitaire.platform.ads`) — additive only, the existing
sealed three-way `suspend fun requestRewarded(reason: AdReason): RewardOutcome` and
`fun showInterstitial()` keep their current signatures and their contract:

- `val rewardedOfferable: StateFlow<Boolean>` — is a rewarded offer worth putting in front of the
  player at all (D-12). `false` means "do not show the dialog; grant the assist silently free".
- `fun preloadRewarded(reason: AdReason)` — non-suspending, fire-and-forget (D-09).

`AdConstants` (NEW, same package) — `object AdConstants` holding `Long` millisecond values only:
`ACCEPT_WAIT_MS` (the D-10 bounded in-dialog wait, 5_000L), `ACTIVITY_WAIT_MS` (the
`ForegroundActivityProvider.awaitActivity` cap), and the preload retry cadence. **No ad-unit ID
ever enters this object** — `AdIds`/`BuildConfig` is the only sanctioned route and `adIdLiteralCheck`
fails the build otherwise.

`AdsReadiness` (NEW, package `com.app.pegsolitaire.platform.ads.consent`) — three payload-free
states: `Unknown`, `Ready`, `Unavailable`.

`ConsentGateway` (NEW, same package) — interface naming **no** UMP or GMA type:
- `val readiness: StateFlow<AdsReadiness>`
- `val privacyOptionsRequired: StateFlow<Boolean>`
- `fun bootstrap()`
- `suspend fun showPrivacyOptions()`

Test fakes (MODIFIED) — `FakeAdGateway` gains `offerable: Boolean = true` and records
`preloadedReasons`; `GatedAdGateway` gains the same two members with `offerable = true`.

Existing contracts to read but not change: `AdReason` (`HINT`, `UNDO` — no `RETRY`, ever, per
Phase 6 D-03), `RewardOutcome` (`Granted` / `Declined` / `Unavailable`),
`ForegroundActivityProvider` (`val current: Activity?`, `suspend fun awaitActivity(): Activity`).
