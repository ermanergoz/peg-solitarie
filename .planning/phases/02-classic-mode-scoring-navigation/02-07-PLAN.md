<objective>
Build the Classic catalog screen — browse 5 board cards (each a mini board-shape preview + name + hole count, D-11) in D-18 ascending order — and select one to play. Build the read-only `BoardPreview` wrapper that reuses the Phase-1 `BoardCanvas` non-interactively for the previews.

Purpose: CLAS-01 requires a browsable catalog of classic boards backed by `LevelRepository.classicCatalog()` (02-04). The previews double as a free visual smoke test that each new `BoardSpec` footprint (dims 7/8/9, incl. the off-center Asymmetric-39) lays out correctly via the generalized `BoardGeometry` (02-04). Tapping a card hands a `levelId` up to the NavHost (02-08) for `Gameplay(levelId)`.

Output: `ui/classic/{ClassicCatalogRoute,ClassicCatalogScreen,ClassicCatalogViewModel,ClassicCatalogUiState,BoardPreview}.kt`, a read-only flag on `BoardCanvas`, + `ClassicCatalogViewModelTest.kt`.

Phase Goal (MVP): As a casual puzzle player, I want to play any of five classic boards from a Home/catalog flow and see stars and a score at the end, so that finishing a board feels rewarding. This plan delivers the "browse and pick a board" entry to that flow.
</objective>
