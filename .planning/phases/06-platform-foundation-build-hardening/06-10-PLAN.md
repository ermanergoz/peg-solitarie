**D-18 — what "offline" actually means here.** `./gradlew check --offline` is the **enforced invariant**. `assembleRelease` is *not* offline-safe until `org.jetbrains.kotlin:compose-group-mapping:2.3.20` is cached: AGP 9.1.0's `produceReleaseComposeMapping` resolves it when minification is on, and it is absent from a fresh Gradle cache. Each machine and CI runner needs **one warm online run**. `check` does not build release, which is why the invariant is scoped to `check`.

**D-16 — signing.** `assembleRelease` produces `app-release-unsigned.apk`; no signing config exists and none may be committed. Debug-sign locally for the smoke test. Real signing is Phase 14 (REL-02), where a signed **internal-testing-track download** — not an `adb install` — is what gets verified.

**Pitfall 4 is what the smoke test is really hunting.** AGP 9.1.0 runs R8 in *strict* full mode, so a build that compiled and shrank cleanly can still throw `NoSuchMethodException` / `InstantiationException` at runtime. That failure reproduces only in release and only when the code path executes — which is why launching and playing a level matters more than the build succeeding.

**Pitfall 11 is the visible one.** `com_google_android_gms_fonts_certs` is an array *of array references*. Plan 06-03 proved all three entries survive via `aapt2 dump resources`, but a human looking at the rendered type is the check that matters for a phase whose success criterion is invisibility.
</context>
