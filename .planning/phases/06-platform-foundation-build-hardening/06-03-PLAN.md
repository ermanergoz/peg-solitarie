**Everything below was measured by running this repo's real build on 2026-08-27** (06-RESEARCH.md § R8). Trust these numbers over any milestone-level document.

**AGP 9.1.0 facts read out of the AGP sources — all three change what you must write:**
- `android.enableR8.fullMode` already defaults to `true`. D-11's "R8 full mode" needs **no** `gradle.properties` entry; adding `=false` would be a regression.
- `android.r8.strictFullModeForKeepRules` defaults to `true`, so `-keep class A` no longer implicitly keeps `A.<init>()`. Any future hand-written keep for a reflectively-instantiated class must spell out `{ <init>(); }`.
- `android.proguard.failOnMissingFiles` defaults to `true`, so `proguardFiles(file("proguard-rules.pro"))` referencing a non-existent file **fails the build**. Create the file first (Task 1), reference it second (Task 2).

**Assumption A2 is the risk in this plan.** Declaring `buildTypes { debug { } }` *configures* the always-present `debug` type rather than creating one, so `sourceSets.getByName("debug").assets.srcDir(roomSchemaDir)` at `app/build.gradle.kts:48` and the `mergeDebugAssets → copyRoomSchemas` dependency at `:54-56` keep their meaning. Evidence for this is indirect. The cheap direct check is `--tests "*MigrationTest"` immediately after adding the block — it is in Task 2's acceptance criteria for exactly that reason.

**Offline note (D-18):** the first minified build on any machine fetches `org.jetbrains.kotlin:compose-group-mapping:2.3.20` (AGP 9.1.0's `produceReleaseComposeMapping` needs it and it is not in a fresh Gradle cache). Run `assembleRelease` **online**. `check --offline` remains the enforced invariant and is unaffected because `check` does not build release.
