**The Hilt scoping trap — this is the one that bites (Pitfall 6).** `@Binds @Singleton fun bind(impl: DefaultX): X` scopes the binding *of `X`*, not of `DefaultX`. If `App` injects the concrete `DefaultForegroundActivityProvider`, Hilt creates a **second, unscoped instance**, and the one the platform layer sees is never fed a lifecycle event: `awaitActivity()` then hangs forever with no exception. The fix is: annotate the **impl class** `@Singleton`, put `attachTo(application)` on the **interface**, and have `App` inject the interface so it never names the concrete type. Note that `NoOpAdGateway` / `NoOpGamesService` deliberately do **not** carry `@Singleton` on the class — that is correct for them because nothing injects their concrete type. Do not pattern-match blindly.

**`onActivityPaused` nulling the reference is deliberate.** Showing a fullscreen ad pauses the host Activity, so `current` becomes `null` *while an ad is on screen*. That is harmless for the intended usage — capture the Activity **before** calling `show()` — and it is the safer default. This must be stated in the interface KDoc so Phase 9 does not "fix" it by holding a strong reference across pause.

**Deliberate divergence from the milestone sketch:** do **not** inject an `@ApplicationScope CoroutineScope` and do **not** use `stateIn`. `resumed.mapNotNull { it?.get() }.first()` needs no scope and no eager sharing. Copy `ChallengeProgress`'s `@Singleton class … @Inject constructor()` *shell*, not its `stateIn` body.

**PLAT-04 gate placement:** `DomainPurityTest.kt` **must not be modified**. Its `@AnalyzeClasses(packages = ["com.app.pegsolitaire.domain"])` scope would make a "nothing outside platform" rule vacuous (Pitfall 7). A separate class with `packages = ["com.app.pegsolitaire"]` is required.

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Android runtime → process-lifetime singleton | Activity instances are pushed in by the framework and outlive nothing; a singleton that keeps one alive leaks a whole view hierarchy. |
| platform layer → everything else | The Activity and (from plan 06-09) the SDK types must not escape `com.app.pegsolitaire.platform..`. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-06-14 | Denial of Service (memory) | `DefaultForegroundActivityProvider` | mitigate | `WeakReference` plus identity-checked clear on pause and destroy. A `lateinit var` or strong `@Singleton` field would leak across every configuration change. Proven by the pause/destroy tests. |
| T-06-15 | Denial of Service (silent hang) | Hilt scoping of the provider | mitigate | `@Singleton` on the impl class and interface-only injection in `App`.
