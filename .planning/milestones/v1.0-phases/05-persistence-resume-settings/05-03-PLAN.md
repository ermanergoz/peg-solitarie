<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| serialized resume blob ⇄ restore | app-written JSON on disk can be corrupted/tampered; feeds board reconstruction and move application |
| stored result row ⇄ UI | persisted result surfaces in Results/catalog |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-03 | Denial of Service | corrupt/tampered resume blob crashes restore | mitigate | `Json { ignoreUnknownKeys = true }` decode wrapped in try/catch → null; `loadSnapshot`/`fromDto` fail-safe to "no snapshot" (asserted) |
| T-05-04 | Tampering | forged moves in the blob applied without validation | mitigate | `SnapshotMapper.fromDto` validates each rebuilt `Move` via `RulesEngine` before trusting it; invalid → null (mirrors T-04-01-U "never trust serialized state") |
| T-05-05 | Tampering | DAO SQL | mitigate | Room bound `:params` only; no string-concatenated SQL |
| T-05-07 | Information Disclosure | PII in stored results/resume | accept | No PII introduced — only local stars/time/score and board geometry; local-only single-user store |
</threat_model>
