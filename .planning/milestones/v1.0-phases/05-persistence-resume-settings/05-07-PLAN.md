## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| serialized resume blob ⇄ restore | persisted JSON drives board reconstruction + move application on Continue |
| lifecycle onStop ⇄ persistence | backgrounding triggers a snapshot write |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-05-03 | Denial of Service | corrupt/tampered resume blob crashes Continue | mitigate | Restore uses `SnapshotMapper.fromDto` fail-safe (05-03): a null result falls back to the normal load path; Continue never crashes |
| T-05-04 | Tampering | forged moves applied on restore | mitigate | `fromDto` validates each move via `RulesEngine` before trusting it (05-03); GameViewModel restores only validated history (mirrors T-04-01-U) |
| T-05-12 | Tampering / data loss | stale Continue survives a solve | mitigate | `clearSnapshot(mode)` on Won and on restart (D-05); onLeaveScreen saves only while Playing (Pitfall 4) — asserted in Task 1 |
| T-05-07 | Information Disclosure | PII in snapshot | accept | Snapshot holds only board geometry + moves + elapsed — no PII; local-only |
</threat_model>
