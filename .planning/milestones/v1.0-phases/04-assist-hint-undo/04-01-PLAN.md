<objective>
## Phase Goal (MVP user story)

**As a** peg-solitaire player, **I want to** ask for a hint that reveals a genuine next winning move and undo my last move, **so that** I can get unstuck and keep playing a puzzle that stays fair and always winnable.

*(Derived from the ROADMAP Phase 4 goal; this milestone is delivered across plans 04-01..04-05 as thin end-to-end slices.)*

## This plan's slice

Deliver the **Undo rescue** capability end-to-end plus the shared **`AdGateway` seam** (D-11) that both Undo and (later) Hint request grants through.

After this plan a player can undo their last move — repeatedly, all the way back to the initial board — with the elapsed timer left untouched, and the Undo control disables itself when there is nothing to undo. Undo requests are auto-granted for free via the no-op `AdGateway` stub, whose Hilt binding is the single swap point for the Slice-2 rewarded-ad implementation.

Purpose: ASST-02 (undo the last move), and establish the platform `AdGateway`/`AdReason`/stub + binding that plan 04-03 (Hint) reuses without change.
Output: `platform/ads` seam (interface + enum + stub + Hilt module), `UndoControl` leaf, `GameViewModel.onUndo()` + `GameUiState.canUndo`, wired through `GameScreen`/`GameRoute`, with extended VM + new Compose/stub tests.
</objective>
