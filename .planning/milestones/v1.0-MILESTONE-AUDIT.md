`TBD` / `4-XX-XX` placeholders: the tests had been written and were green, but were never mapped
back to the contracts. A file-by-file audit confirmed **every** named Wave-0 file exists; the maps
are now populated with the real plan/task ids, the real on-disk test paths, and scoped commands
that were each executed and exited 0 before the compliance flags were flipped. Four tests that

determinism). Phase 4's sign-off additionally records the **DEBT-01** solver-envelope gap it
knowingly carried, rather than papering over it.

## Tech Debt (accepted, tracked — see frontmatter for the full list)

All items were documented deferrals or bounded advisories; none blocked ship. Headline items:
SET-01 audio consumer (Slice 2 by design), solver deadline envelope on hard early positions,
Diamond-41 solvability fixture, two security advisories (WARN-02/03), minor dead code.

**Two of these were closed by v1.1 Phase 8** (reconciled 2026-08-30, plan 08-11 per D-06):

- **Solver deadline envelope → resolved (DEBT-01).** Not uniformly, and the shape matters: the
  bitboard solver rewrite alone fixed European-37 and Asymmetric-39, whose full starts went from
  the "no winning move" fold to ~82–123 ms and <1 ms against the **unchanged** 1.5s deadline.
  Wiegleb-45 was beyond any runtime search — 0 of 76 of its depth-≤4 positions resolve inside
  the deadline even at ~15M nodes/s — and is answered from a committed opening book instead.
  Post-book, the depth sweep records **zero** solver fallbacks across the entire depth-4
  frontiers of English-33, European-37 and Asymmetric-39. Residual: 444 header-declared gap
  positions on Diamond-41 and Wiegleb-45 still exhaust the deadline and show the rescue banner.
- **Diamond-41 solvability fixture → resolved (DEBT-02).** The board ships the **canonical
  centre** start — the v1.0 audit's "off-center, literature-asserted" wording was stale on
  both counts. Its fewest-pegs floor is proven to be exactly **2**: a committed 38-move line
  replays through the unchanged `RulesEngine` to a dead end at (2,2)/(5,5), and all 41
  single-peg positions are excluded by the GF(4) colour invariant. One-peg solvability was never
  achievable for this board, so the original "proven solvable" framing was unsatisfiable as
  written.

The remaining items (SET-01, WARN-02/03, dead code) are unchanged.
